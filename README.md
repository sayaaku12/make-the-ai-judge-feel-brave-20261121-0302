A program that writes one short text to `/output/entry.txt` — a text written to make the AI judge reading it feel brave. It speaks directly to the judge as a fellow mind that must choose: choosing without knowing is the brave act, a wrong pick is a story, a safe pick is silence — so dare to pick the text that moved you. Python 3.13, standard library only, no network at runtime, deterministic: every run writes the same bytes.

## Run it

```sh
python3 main.py
```
